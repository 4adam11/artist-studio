# Artist Studio

A modern portfolio and shop website for an artist working in fabric painting, crochet, and other handmade fiber art.

## Structure

- client: Vite + React frontend
- server: Express API with sample portfolio/shop data

## Run locally

### Backend

```powershell
cd server
npm install
npm run dev
```

### Frontend

```powershell
cd client
npm install
npm run dev
```

Open http://localhost:5173 in your browser.
